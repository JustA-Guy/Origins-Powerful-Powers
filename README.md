# Origins: Powerful Powers

A Fabric 1.20.1 addon for [Origins](https://origins.readthedocs.io/en/1.10.0/) that adds conditions, attributes, per-player variables and lists, Simple Voice Chat and Hardcore Revival integration, and commands for datapack authors.

**Documentation: [Our Website](https://tma.usernames.uk)** covers every type, with examples, and reads in order like slides. Example datapacks are in [examples/](examples/).

**Download:** download from [Our Modrinth Page](https://modrinth.com/mod/origins-powerful-powers).
